# Research technical claims responsibly

## When to use

Use this skill when the answer depends on current technical facts, tool capabilities, version compatibility, benchmarks, or vendor guidance.

## Procedure

Prefer official documentation and primary sources. Verify product/version/date, compare independent evidence where useful, distinguish facts from inference, and cite links. Never fabricate sources, benchmarks, or capabilities.

## Expected outputs

- Question, constraints, and date/version scope
- Findings with primary-source links and evidence dates
- Fact/inference separation, recommendation, caveats, and inaccessible sources

## Quality checks

- Prefer official documentation and primary sources; compare independent evidence when useful.
- Verify version and publication/update date before applying advice.
- Never invent citations, benchmarks, or unsupported tool capabilities.
