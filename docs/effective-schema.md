# Effective status snapshot schema

## Output file

state/effective.json is generated by python scripts/status_snapshot.py. It is a point-in-time reconciliation, not a background monitor. Schema version is 1.

## Top-level fields

| Field | Type | Meaning |
|---|---|---|
| schema_version | integer | Schema version; currently 1. |
| generated_at | string | UTC ISO 8601 timestamp for when this snapshot was generated. |
| agents | array | Agent snapshots, one per declared or observed agent ID. |
| tasks | array | Task snapshots, one per declared or observed task ID. |
| github | object, optional | Present only when gh is installed and both GitHub queries succeed. Contains available, issues_count, and pull_requests_count. Omitted otherwise; a warning is printed to stderr. |

## Agent fields

Each item in agents contains:

| Field | Type | Meaning |
|---|---|---|
| agent_id | string | Agent identifier from the declared state or telemetry. |
| declared | string or null | Status declared in the Active delegations table, normalized to running, idle, blocked, completed, cancelled, or unknown. Missing/unsupported declaration is null. |
| observed | string or null | Status supported by the latest usable event. Explicit details.status, details.agent_status, or details.outcome values are used when recognized. A delegate event with details.target indicates running. An event action alone never proves failure or completion. Null means no reliable status was inferred. |
| drift | boolean | true only when both declared and reliably observed statuses exist and differ. Missing evidence never creates drift. |
| last_event_age_seconds | integer or null | Non-negative age of the latest valid event for this agent at generation time; null if none. |
| staleness | string | FRESH when age is under 900 seconds; STALE from 900 through 86,400 seconds; UNKNOWN when no valid event exists or age is greater than 86,400 seconds. Thresholds can be overridden with CLI options. UNKNOWN is not a claim that an agent failed. |

## Task fields

Each item in tasks contains:

| Field | Type | Meaning |
|---|---|---|
| task_id | string | Task ID from the Backlog and task ownership table, Active delegations, or telemetry story. |
| declared | string or null | Normalized status from the project-state Backlog table, or null if no status is declared. |
| observed | string or null | Status supported by telemetry details.task_status, a matching GitHub issue state (DONE for closed, IN_PROGRESS for open), or an open matching PR (IN_REVIEW when no issue/telemetry status is available). Null means no reliable task status was found. |
| drift | boolean | true only when declared and observed statuses both exist and differ. |
| evidence | array | Observations supporting the status. Telemetry evidence includes source, event ID, and timestamp. GitHub issue evidence includes source, issue number, and state. PR evidence includes source, PR number, state, and draft flag. URLs may be absent when not returned by gh. An evidence record documents a query result; it is not proof of implementation or acceptance. |

## Reconciliation rules and limits

- project-state.md is parsed only in the documented Backlog and task ownership and Active delegations Markdown tables. Other prose is not interpreted as a status.
- Telemetry is read from .claude/telemetry/activity.jsonl; malformed records are skipped with warnings. Latest events are selected by parsed UTC timestamp, not file order.
- The gh CLI is optional. If absent, or if either query fails, the snapshot still works and omits the github object.
- A missing event is UNKNOWN, not failed. An event older than 24 hours is also UNKNOWN; the event age is retained for diagnosis. Drift is evaluated separately from staleness when a reliable observed status exists.
- Claims are context only: the snapshot reports a mismatch; it does not decide which claim is true without evidence. Review evidence and reconcile source conflicts before taking action.
- This script does not run CI itself and does not infer that code was tested, reviewed, merged, or deployed from an agent event.
