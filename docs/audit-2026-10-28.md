## Decisions for the sponsor

- **M2 — provisioning approval is self-certified.** `apply` accepts any non-empty `approved_by` with the printed digest, so an agent that can edit the plan can approve it; the real control is the `ask` rule on `provision_project.py apply`. Options: interactive TTY confirmation of the digest at `apply`, a CP approval record outside the plan file, or at minimum `approved_by == plan.owner`.
- **M5 — gate and approval records can be forged.** `check_gates.py`, `check_approvals.py` and `detect_conflict.py` validate shape only (no commit SHA, no artifact hash recomputation; `decided_by` accepts any string containing "human"). Options: bind records to `commit_sha`/artifact hashes the checker recomputes, and put `.claude/gates/`, `.claude/approvals/` and `.claude/disagreements/` behind deny/ask rules.
- **ROI valuation.** `templates/sprint-roi-report.md` values tokens at an API price while `standards/sprint-sizing.md` rules out API-equivalent budgets; keep as an estimate or remove.
- **Coordinator rules in CLAUDE.md.** About 300 words only the orchestrator needs load into every subagent; moving them saves about 400 tokens per delegation but removes them from sessions started without `--agent`.

## Backlog (fix specified, not yet done)

- **M4:** `append_telemetry.py` and `add_lesson.py` check only a few key names or words; scan values for token patterns (`ghp_`, `github_pat_`, `AKIA`, PEM headers, `Bearer`) and widen the key list.
- **L4:** `release_claim.py` deletes any claim; compare the claim's `run_id` and use `--force-with-lease`.
- **L5:** claim scripts read the shared `FETCH_HEAD`; fetch into a unique ref.
- **L6:** `coordinator_lock.py` takeover race and unchecked release; use `fcntl.flock` and check the holder.
- **L7:** worktree names can collide (`a-b` + `c` vs `a` + `b-c`); use an unambiguous separator or verify the branch before removal.
- **L8:** the cleanup confirmation reads stdin and can be piped; require a TTY.
- **L9:** telemetry and lesson appends race; hold a file lock across read and append.
- **Lessons as instructions:** any agent can append a binding lesson; consider orchestrator or human approval for new lessons.
- **Hook reads:** `cat`/`head`/`grep` may read any file, including outside the repository.
- **Test telemetry:** hook tests write denial events into the real `.claude/telemetry/activity.jsonl`; a test-only log path would keep analysis clean.
