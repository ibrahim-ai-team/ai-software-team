## Remaining decisions and risks

- **Activate the approver list:** create `.claude/human-approvers.json` with your GitHub username. Until then, approval records accept any non-empty `approved_by` (writes are still human-only).
- **Bash reads outside the repository:** `cat`/`grep`/`head` can still read any file the OS user can; only the Read tool is restricted for the credential folders.
- **Gate records are not bound to a commit:** writes now need a human prompt, but `check_gates.py` still does not compare a record with the PR head commit.
- **ROI valuation:** `templates/sprint-roi-report.md` values tokens at an API price while `standards/sprint-sizing.md` rules out API-equivalent budgets; keep as an estimate or remove.
- **Coordinator rules in CLAUDE.md:** moving the ~300 orchestrator-only words saves ~400 tokens per delegation but removes them from sessions started without `--agent`.
